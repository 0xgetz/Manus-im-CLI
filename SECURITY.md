# Security Policy

The maintainers and contributors of **Manus-im-CLI** take security very seriously. We appreciate your efforts to responsibly disclose security vulnerabilities.

---

## 📋 Supported Versions

We provide security updates and patches for the following versions of `Manus-im-CLI`:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability within `Manus-im-CLI`, please do not disclose it publicly until our team has addressed and resolved it. 

### Reporting Channel
- **Email**: Please report vulnerabilities directly to our security contact at **[api-support@manus.ai](mailto:api-support@manus.ai)** [1].
- **Encrypted Communication**: If required, request our PGP key via email for sensitive disclosures.

### What to Include in Your Report
To help our security team triage and investigate the issue effectively, please include:
1. **Description**: A clear description of the vulnerability, its potential impact, and the components affected.
2. **Steps to Reproduce**: Detailed steps, proof-of-concept scripts, or configuration examples required to reproduce the issue.
3. **Environment**: Operating system, Python version, and `Manus-im-CLI` version.

---

## ⏱️ Disclosure Timeline & Process

1. **Acknowledgment**: You will receive an acknowledgment of receipt from our security team within **48 hours**.
2. **Investigation & Triage**: The team will investigate the report and assess its severity and impact.
3. **Patch & Release**: If confirmed, we will develop a security patch, test it thoroughly, and release an updated version (`0.1.x+`).
4. **Public Disclosure**: Once the patch is publicly available, we will credit the reporter (unless requested otherwise) and publish a security advisory.
